Task 4: Home Page

Home Users Posts

This is the home page of my website. In this task we were assigned to build a CRUD application using Vanilla JavaScript and the Fetch API with JSONPlaceholder.

This application made should be able to:

  • Display a list of users and allow viewing posts for a selected user.
  • Implement Create, Edit, and Delete post
  • Use Optimistic UI updates for all CRUD operations. functionality.
  • Implement client-side search and filtering for posts.
  • Implement client-side pagination. (optional)
  • Handle loading, empty, and error states gracefully.
  • Display user-friendly error messages for failed network requests.
